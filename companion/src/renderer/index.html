Kéo biểu tượng ⋮⋮ trên mỗi tile để đổi vị trí. Nhớ Save grid để đẩy lên board.

BLE connected = volume shows macOS HUD. BLE off/disconnected = volume uses companion 3% over Wi‑Fi (no HUD). Mute/play/next/prev need BLE.

On = discoverable for pairing / reconnect. Off = hide from Bluetooth scan.

Defaults: dim 30s at 30% → clock 120s → dim2 300s at 30% → off 1800s. Set a timeout to 0 to disable that stage.
