TouchDeck — Cài firmware ESP

JC8048W550C · ESP32-S3 · 16 MB flash · Cắm USB-C data, dùng Chrome hoặc Edge.

Trước khi flash

  1. Cắm board JC8048W550C vào Mac bằng cáp USB-C có data.
  2. Chuẩn bị file firmware: chạy ./scripts/prepare-web-firmware.sh từ repo (hoặc dùng companion đã build).
  3. Nhấn Kết nối USB → chọn cổng serial của ESP32-S3.
  4. Nhấn Ghi firmware. Không cần giữ nút BOOT nếu board tự vào download mode.
