Màn hình trên desk

Lưới tuỳ chỉnh (ví dụ 5×2). Thanh trạng thái góc phải:

IconÝ nghĩa
Volume %Mức loa Mac (Companion đẩy qua WS)
BluetoothXanh = đã ghép HID
⇅Xanh = Companion đã nối — nút mở app mới bật
Wi‑FiXanh = STA; vàng = đang AP setup

Chạm tile app để mở; Vol ± / Mute gửi HID khi đã ghép Bluetooth.

Hướng dẫn sử dụng

1. Flash firmware lần đầu

  1. Cáp USB‑C có data + trình duyệt Chrome hoặc Edge.
  2. Mở trang Cài firmware → Kết nối USB → Ghi firmware (nên xoá flash lần đầu).
  3. Board phát AP TouchDeck-Setup-XXXX (mật khẩu touchdeck) nếu chưa có Wi‑Fi.

Đi tới trình cài đặt →

2. Cấu hình Wi‑Fi

  1. Vào AP hoặc mở http://192.168.4.1 / sau đó http://touchdeck.local
  2. Nhập SSID, mật khẩu, tên thiết bị, hostname, mật khẩu OTA → Save & Restart

3. Bluetooth (media)

  1. Bật Bluetooth + Pairing mode trên portal
  2. Mac → System Settings → Bluetooth → ghép TouchDeck
  3. Volume Up/Down khi đã ghép hiện HUD hệ thống

4. Companion trên Mac

Tải bản đóng gói rồi mở — không cần Node/pnpm:

Tải Companion (DMG · Apple Silicon) Mọi bản phát hành
  1. Mở file .dmg → kéo TouchDeck Companion.app vào Applications.
  2. Chạy app (hiện trên menu bar). Lần đầu nếu macOS chặn: chuột phải → Open.
  3. Tab Connect → Scan / nhập touchdeck.local port 81 → Connect.
  4. Accessibility: bật TouchDeck Companion (cho cảnh báo Cursor/Codex).

Intel Mac hoặc tự build: xem README (pnpm run dist).

5. Dùng hàng ngày

  • Mở app — chạm tile App (cần Companion WS; tile mờ nếu chưa nối)
  • Volume — BLE = HUD macOS; không BLE = bước 3% qua Companion
  • Mute / play / next / prev — cần BLE; không có thì tile disabled
  • Idle — dim → đồng hồ → dim 2 → tắt; chạm wake không kích hoạt nút (nhấc tay rồi chạm lại)

Tuỳ chỉnh lưới

Mở http://touchdeck.local/grid hoặc Companion → tab Grid: đổi cột/hàng, label, icon SD, action (volume / app + bundle ID) → Save to device.
