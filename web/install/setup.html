TouchDeck — Install ESP firmware

JC8048W550C · ESP32-S3 · 16 MB flash · Use a USB-C data cable with Chrome or Edge.

Before you flash

  1. Plug the JC8048W550C into your Mac with a USB-C cable that carries data.
  2. Prepare firmware: run ./scripts/prepare-web-firmware.sh from the repo (or use a release build).
  3. Click Connect USB → select the ESP32-S3 serial port.
  4. Click Write firmware. Holding BOOT is usually not required if the board enters download mode automatically.
